UART transmitter

Frame interpretation

Engineering concept

UART is asynchronous. The idle line is high, the start bit is low, data is transmitted least-significant bit first, and a stop bit is high. The parity option adds one parity bit.

I²C bus transaction

Transaction decoder

Engineering concept

I²C uses open-drain SDA and SCL with pull-ups. A START occurs when SDA falls while SCL is high; a STOP occurs when SDA rises while SCL is high. Each byte is followed by a ninth ACK/NACK clock.

Idealized I²C signals

The plot illustrates the START, address+write, ACK/NACK, data, ACK/NACK and STOP sequence. It is not an electrical or rise-time simulation.

SPI transfer

Full-duplex interpretation

Engineering concept

CPOL sets idle clock polarity. CPHA selects whether sampling happens on the first or second clock edge. MOSI and MISO can carry one bit simultaneously per clock cycle while chip select is asserted.
