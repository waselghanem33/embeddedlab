Unified Uno laboratory

Build a D9 PWM LED circuit and D2 interrupt button. Edit the model program, apply it, run time, and observe all instruments together. This is a bounded event model, not compiled Arduino C++ or a general electrical solver.

1 · Breadboard and Uno connections

Click two terminals or holes to add a jumper. A–E in each numbered column share a net. F–J share a separate net. Components have fixed named terminals; connect them using jumpers.

2 · Editable model firmware
Supported instructions only. Apply resets the simulation. PWM is a modeled high-tick count (0 to TOP+1), STEP is the change on each INT0 ISR, TIMER enables compare events.
Register inspector (derived model values)
Timer1 Fast PWM mode 14, non-inverting OC1A; compare events are counted once per period. Endpoint PWM values are idealized; register OCR1A is not literal at the full-on endpoint. No instruction timing, ISR latency or full AVR register emulation.
3 · Synchronized instruments
Three ideal PWM periods at current settings, not a historical oscilloscope capture. D2 is its current logic level. Event log below records changes in simulated time.
4 · ENCE4380 guided experiment
Predict the initial frequency, duty cycle and LED current. Press the button, observe the ISR count and PWM change. Disable global interrupts, generate two falling edges, then enable interrupts and explain flag coalescing.
