Timers, PWM and interrupts

Arduino Uno / ATmega328P, 16 MHz. Educational event model, not an AVR emulator.

Timer1 CTC and Fast PWM (mode 14)

Predict frequency and duty cycle before changing TOP or prescaler. PWM output OC1A is D9; this model excludes special endpoint cases.
External interrupt INT0 (D2)
Each button is one ideal event. Disabled external interrupts are not serviced in this model; pending flags, priority, LOW-level retriggering and latency are not simulated. Timer compare button represents an enabled Timer1 compare ISR independently of the external interrupt control.
volatile bool event = false;
void motion() { event = true; }
void setup() {
  pinMode(2, INPUT_PULLUP);
  attachInterrupt(digitalPinToInterrupt(2), motion, FALLING);
}
void loop() {
  if (event) { event = false; /* process event */ }
}
Single-bit flag example: multiple events can coalesce; use an atomic counter snapshot when every event matters. A timer interrupt is hardware-generated, even when configured in software. A millis-based callback is cooperative scheduling, not an ISR.
